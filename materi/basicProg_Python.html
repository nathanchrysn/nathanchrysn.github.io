Apa itu Variabel?

Bayangkan variabel seperti kotak penyimpanan berlabel. Kamu bisa taruh sesuatu di dalam kotak itu, memberinya nama, lalu mengambil atau mengganti isinya kapan saja. Dalam Python, variabel bekerja persis seperti itu: sebuah nama yang menyimpan sebuah nilai, supaya nilai tersebut bisa dipakai lagi nanti di kode kita.

sintaks_variabel.py
# Cara membuat variabel di Python
nama_variabel = nilai
Aturan penamaan variabel di Python:
  • Tidak boleh diawali dengan angka (contoh: 2skor ❌, skor2 ✅)
  • Tidak boleh mengandung spasi (gunakan garis bawah "_" sebagai gantinya)
  • Bersifat case-sensitive — Nilai dan nilai dianggap variabel yang berbeda!
  • Sebaiknya menggunakan nama yang jelas maknanya, misalnya umur, bukan x

Contoh & Pembahasan

contoh_variabel.py
nama = "Budi"
umur = 13
tinggi_badan = 150.5

print(nama)
print(umur)
HASIL (OUTPUT)Budi 13

Yuk kita bahas: baris pertama membuat variabel nama yang isinya teks "Budi". Baris kedua membuat variabel umur berisi angka 13. Baris ketiga membuat variabel tinggi_badan berisi 150.5. Perintah print() di baris terakhir menampilkan isi variabel ke layar — perhatikan, variabel tinggi_badan tidak ditampilkan karena kita tidak memerintahkan print(tinggi_badan).

Kaitan dengan kehidupan nyata: Setiap kali kamu main gim dan skor kamu bertambah, atau saat aplikasi menyimpan nama profil dan foto kamu — semua itu disimpan dalam variabel di balik layar!

Apa itu Tipe Data?

Tipe data adalah jenis dari nilai yang disimpan sebuah variabel. Sama seperti di dunia nyata ada jenis barang yang berbeda (uang, buku, baju), di Python juga ada beberapa jenis data dasar yang perlu kamu kenal:

Tipe DataKegunaanContoh
Integer (int)Bilangan bulat10, -5, 100
FloatBilangan desimal3.14, 0.5
String (str)Teks / kalimat"Halo"
Boolean (bool)Benar / SalahTrue, False

Untuk mengecek tipe data sebuah variabel, Python punya fungsi bawaan bernama type().

Contoh & Pembahasan

contoh_tipe_data.py
skor = 100
harga = 15000.50
julukan = "Sang Juara"
menang = True

print(type(skor))
print(type(harga))
print(type(julukan))
print(type(menang))
HASIL (OUTPUT)<class 'int'> <class 'float'> <class 'str'> <class 'bool'>

Perhatikan hasilnya: skor (angka bulat) dikenali sebagai int, harga (ada koma desimal) sebagai float, julukan (teks berkutip) sebagai str, dan menang (True/False) sebagai bool. Python otomatis mengenali tipe data — kamu tidak perlu menuliskannya secara manual!

Hati-hati: "13" (pakai tanda kutip) itu String, beda dengan 13 (tanpa kutip) yang Integer! Ini kesalahan yang paling sering dilakukan pemula, jadi ingat baik-baik ya.
Kaitan dengan kehidupan nyata: Formulir pendaftaran sekolah punya kolom dengan "tipe" berbeda: nama (teks/String), umur (angka/Integer), tinggi badan (desimal/Float), dan "sudah lunas SPP?" (benar-salah/Boolean).

Apa itu If-Else (Percabangan)?

If-Else adalah struktur yang membuat program bisa mengambil keputusan berdasarkan suatu kondisi — persis seperti kita sehari-hari. Contoh: "Jika hujan, maka aku bawa payung. Kalau tidak, aku pakai topi biasa." Itulah cara berpikir if-else!

sintaks_ifelse.py
if kondisi:
    # dijalankan jika kondisi benar
else:
    # dijalankan jika kondisi salah
Operator perbandingan yang sering dipakai:
  • == sama dengan  •  != tidak sama dengan
  • > lebih besar  •  < lebih kecil
  • >= lebih besar / sama dengan  •  <= lebih kecil / sama dengan
Awas jebakan! Tanda = (satu) itu untuk MENGISI nilai ke variabel, sedangkan == (dua) untuk MEMBANDINGKAN dua nilai. Jangan sampai ketuker!

Contoh & Pembahasan

cek_kelulusan.py
nilai = 80

if nilai >= 75:
    print("Selamat, kamu LULUS!")
else:
    print("Semangat, coba lagi ya!")
HASIL (OUTPUT)Selamat, kamu LULUS!

Pembahasan: Python mengecek kondisi nilai >= 75. Karena nilai berisi 80, dan 80 >= 75 bernilai benar, maka blok kode di bawah if yang dijalankan, dan blok else dilewati begitu saja. Kalau nilai misalnya 60, maka program akan mencetak "Semangat, coba lagi ya!" karena kondisinya salah.

Kaitan dengan kehidupan nyata: Lampu lalu lintas ("jika merah, berhenti; jika hijau, jalan"), mesin ATM ("jika PIN benar, buka; jika salah, tolak"), dan sistem menang-kalah pada gim semuanya menggunakan logika if-else.

Apa itu Loop (Perulangan)?

Loop digunakan untuk mengulang sebuah blok kode beberapa kali, tanpa harus menulis ulang kode yang sama berkali-kali. Bayangkan kalau kamu harus mengabsen 30 siswa satu per satu secara manual dengan menulis kode berbeda untuk tiap siswa — melelahkan, kan? Dengan loop, cukup satu blok kode yang diulang otomatis.

sintaks_loop.py
# perulangan FOR (jumlah pasti)
for i in range(5):
    print(i)

# perulangan WHILE (selama kondisi benar)
while kondisi:
    # kode yang diulang

range(5) menghasilkan urutan angka 0, 1, 2, 3, 4 — jadi ada 5 angka, dan perulangan berjalan sebanyak 5 kali.

Contoh & Pembahasan

total_belanja.py
total = 0
for angka in range(1, 6):
    total = total + angka

print("Total:", total)
HASIL (OUTPUT)Total: 15

Pembahasan: range(1, 6) menghasilkan angka 1, 2, 3, 4, 5. Setiap kali loop berjalan, nilai angka ditambahkan ke total. Jadi: 0+1=1, 1+2=3, 3+3=6, 6+4=10, 10+5=15. Pola "menjumlahkan sedikit demi sedikit" ini disebut akumulasi, dan sangat mirip dengan cara kasir menjumlahkan total belanjaanmu satu per satu di kasir minimarket!

Hati-hati dengan while: Pada perulangan while, jangan lupa mengubah nilai variabel kondisinya di dalam loop. Kalau lupa, program akan berputar terus tanpa henti — ini disebut infinite loop!
Kaitan dengan kehidupan nyata: Aplikasi absensi sekolah yang mengecek nama semua siswa satu per satu, lagu yang diputar "repeat", dan mesin cuci yang mengulang siklus bilas beberapa kali — semuanya menerapkan konsep loop.

Kenapa Belajar Konsep Ini Penting?

Variabel, Tipe Data, If-Else, dan Loop adalah 4 bahan dasar yang dipakai untuk membangun hampir semua program komputer — mulai dari kalkulator sederhana sampai game dan aplikasi kecerdasan artifisial (KA). Tapi manfaatnya nggak berhenti di situ saja.

Manfaat belajar konsep dasar pemrograman:
  • Melatih berpikir logis dan sistematis (computational thinking) — memecah masalah besar jadi langkah-langkah kecil
  • Melatih ketelitian — satu tanda baca salah saja, program bisa error
  • Membantu memahami teknologi di sekitar kita, bukan cuma jadi penggunanya saja
  • Membuka peluang di banyak bidang: sains, seni digital, bisnis, hingga karier di masa depan

Menariknya, kemampuan berpikir logis ini juga berguna di luar coding — misalnya saat menyusun jadwal belajar, merencanakan uang jajan, atau menyelesaikan masalah sehari-hari selangkah demi selangkah.

Contoh nyata: Aplikasi ojek online mencocokkan penumpang dan pengemudi (if-else + loop untuk mengecek banyak pengemudi terdekat), aplikasi belanja menghitung total harga (variabel + loop), dan filter foto di media sosial mengubah tampilan gambar berdasarkan pilihanmu (if-else).
Yuk, lanjut ke bagian Aktivitas Interaktif untuk mencoba langsung konsep-konsep ini dengan tanganmu sendiri!
